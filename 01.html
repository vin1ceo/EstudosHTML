Olá, seja bem vindo ao meu primeiro site!

Objetivo é criar um sistema do zero:

Considerando as seguintes linguagens:

  • HTML
  • CSS
  • JavaScript
  • React
  • Django
  1. Conceito

    REMIND.ME é uma plataforma web inovadora focada na criação de presentes digitais únicos e significativos. Em um mundo onde presentes físicos muitas vezes perdem seu valor, o REMIND.ME oferece uma maneira de transformar memórias e histórias compartilhadas em um "Painel de Memórias" uma landing page personalizada, interativa e cheia de emoção. O objetivo é ir além de um simples presente, proporcionando uma experiência imersiva que celebra a conexão entre as pessoas, seja em aniversários, datas comemorativas ou simplesmente como uma demonstração de carinho.

  2. Funcionalidades Principais

    O sistema será construído com um conjunto de funcionalidades para permitir a máxima personalização e impacto emocional:

    • Construtor de Páginas Intuitivo: Uma interface amigável para que qualquer usuário possa montar seu Painel de Memórias, adicionando e organizando diferentes seções.
